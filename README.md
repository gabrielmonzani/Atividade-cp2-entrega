# Atividade-cp2-entrega
Este é um projeto acadêmico de segundo semestre de ADS 

 Sobre o Projeto
 O TechQuiz é uma aplicação web interativa desenvolvida como parte do Checkpoint 2 da disciplina de Desenvolvimento Front-end para Web. O projeto consiste em um quiz de perguntas e respostas voltado para tecnologia, construído com foco em lógica de programação, manipulação dinâmica do DOM, acessibilidade e experiência do usuário.   🚀 Funcionalidades PrincipaisBanco de Dados Dinâmico: Carregamento assíncrono de questões através de um arquivo JSON externo (fetch).   Perguntas Aleatórias: O sistema armazena um banco robusto com 50 questões e seleciona 10 perguntas aleatórias a cada nova partida.Fluxo Completo de Jogo: Validação de nome do jogador, exibição de perguntas individuais, feedback imediato com explicações detalhadas e links oficiais de fontes.   Ranking Local: Armazenamento e persistência do placar da sessão utilizando o sessionStorage.   Acessibilidade (A11y): Navegação totalmente funcional por teclado (Tab e Enter), foco visível, contraste adequado e pistas visuais (texto e bordas) para acertos e erros.   Design Responsivo: Interface moderna e adaptada para diferentes tamanhos de tela (mobile e desktop).
